# 第二场真实对话测试 · 2026-09-21

目的：验证同一套项目格式、生成适配器和合成器能用于另一部电影的两名新角色，而不是只能运行最初的饭桌工程。

## 实际操作

选择《绣春刀》谈价片段，改为虚构的 AI 会员收费故事。比较两个来源的首尾、原字幕与对话顺序，保留完整谈价结构。使用新项目与新角色的本场音色／表演参考，没有复用旧演员音频。

九句改词使用公开包中的 IndexTTS 2.5 适配器完整生成，末句使用原声。项目 CLI 负责校验、渲染和最终容器解码。片源整理、外部 ASR、声纹诊断、音量匹配与原片对照样片是制作步骤，不伪装成已内置的一键功能。

| 项目 | 观察结果 |
|---|---|
| 保留时间轴 | 38.84 秒 |
| 角色 | 两名新角色 |
| 发言 | 10 次，其中 9 次整句生成、1 次原声保留 |
| 词句诊断 | 外部 small／medium ASR 交叉检查；一处多音字疑点改成无歧义用词后整句重录 |
| 角色诊断 | 9 条新录音的最近参考均为预期角色；短句结果不作身份裁决 |
| 输出检查 | 最终 MP4 完整解码，10 次发言均非空且与预期混音一致，尾部时长覆盖末句 |
| 字幕 | 长句按实际词时间提案分块，短句保留整句；抽查 16 处画面 |
| 听觉验收 | 已制作原片／改词对照；用户尚未给出本轮试听结论 |

## 制作中发现的实际问题

- 下载视频的容器时长约 53.79 秒，音轨实际解码到约 53.243 秒。使用共同有效末端 53.24 秒，并保留元数据与边界记录；未截掉末句来绕过检查。
- 一处原稿生成超过目标窗约 0.14 秒。整句调整后，最终采用修改文字、自然时长的完整新 take，未剪掉尾字。
- 两句生成反问的电平偏高。按对应原句的强弱关系做显式增益调整，原声名句保持原素材。
- 单字反问与半秒称呼的不同 ASR 结果不一致，标为短句识别局限，没有把第二个模型当作听觉裁决。

这次测试验证真实素材上的工作流迁移、装配与修订方法。它不证明通用声线复刻、逐帧口型一致或所有表演均获认可。原电影、参考声线、生成音频和本机工程都不在发行包内。
